# Groovebox · 节奏工作台

中文浏览器音乐工作台，使用原生 JavaScript 和 Web Audio，无需安装依赖或构建。

在线版本：https://groovebox-studio-james.dkoeo.chatgpt.site/

## 功能

- 8 个声部：6 种鼓音色、贝斯、旋律；16 步音序器。
- A–D 四个段落、段落复制、串联播放、节奏生成与随机变奏。
- 钢琴卷帘：添加、拖动、框选、复制粘贴、移调、调整时值；每个旋律声部每步一个音符。
- 每步力度、触发概率、连击、时值。
- 分轨音量、声像、静音、独奏；滤波、失真、延迟、混响。
- 演奏垫、键盘演奏、量化录入、撤销和重做。
- 音频采样导入、波形预览、起止裁切、反向播放和原音高设置。
- 本地作品库、命名、多作品、副本、自动保存和备份恢复。
- 导入／导出包含采样的 JSON 工程；导出立体声 44.1 kHz WAV。

## 启动

### 离线单文件

下载 `Groovebox.html`，使用现代浏览器直接打开。无需联网；首次播放需点击播放按钮。

### 源码版本

在仓库根目录运行（需已安装 Python）：

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

访问 http://127.0.0.1:8765/ 。也可使用其他静态文件服务器提供 `dist/`。

## 数据与采样

作品和采样保存在当前浏览器的 IndexedDB 中，按访问地址隔离。在线版、本地服务器版与离线文件之间不会自动同步；更换设备或访问地址时，请先导出 JSON 工程再导入。

单个采样最多 8 MB、30 秒、双声道，工程内采样总量最多约 24 MB。音频格式取决于浏览器解码支持。清理浏览器站点数据会删除本地作品，建议定期导出备份。播放时请保持页面在前台。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `dist/index.html` / `style.css` | 页面与响应式样式 |
| `dist/project.js` | 工程模型、预设、旧版本迁移与校验 |
| `dist/audio.js` | 音频合成、采样、调度、效果器与 WAV 渲染 |
| `dist/app.js` | 音序器、混音与演奏控制 |
| `dist/stage3.js` | 钢琴卷帘、音符表现、采样与作品库交互 |
| `dist/storage.js` | IndexedDB 自动保存、备份与作品库 |
| `Groovebox.html` | 可直接打开的完整离线版 |
| `.openai/hosting.json` | 现有 Sites 静态部署配置 |

当前版本已验证钢琴卷帘编辑、采样裁切与反向播放、大采样跨浏览器重启恢复、自动备份恢复、实际音频输出、WAV 下载，以及 320／390／768 像素宽度布局。
